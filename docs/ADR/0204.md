# Actividad 4 — Historias de usuario (biblioteca)

## 1. Historias de usuario

**Historia 1 — Socio**
Como Socio de la biblioteca quiero saber si membresia sigue activa para poder coger un libro prestado.

**Historia 2 — Bibliotecario**
Como bibliotecario, quiero comprobar si esta persona es socio, para poder prestarle un libro.

**Historia 3 — Administrador del sistema**
Como administrados del sistema quiero comprobar la cantidad de socios que pidieron libros el último año, para dar de baja a los que no pidieron

## 3. Criterios de aceptación (Historia 1)

- **Criterio 1:** Dado que un socio tiene su membresía activa, cuando consulta el estado de su membresía, entonces el sistema le muestra que puede pedir libros prestados.
- **Criterio 2:** Dado que el socio no tiene su membresia activa, cuando consulta el estado de su membresía, entonces el sistema le muestra que no puede coger libros prestados.
